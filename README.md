# CoreInk Humidor & Environmental Monitor (雪茄箱 / 室内环境监测仪)

基于 **M5Stack CoreInk** 电子墨水屏主控与 **Unit ENV-Pro (Bosch BME688)** 传感器的高精度便携式环境监测站。针对雪茄养护、恒温恒湿储存及室内空气质量监测场景深度定制。

---

## 🌟 核心特性

- **纯正正相白底黑字显示**：利用 1.54 英寸 200×200 E-Ink 电子墨水屏，呈现纸质般的阅读体验，强光下清晰可见，断电保留最后一帧内容。
- **全方位环境感知**：
  - 实时温湿度（精度达 0.1°C / 0.1% RH，标配 65% RH 黄金雪茄养护参考线）。
  - 大气压强与高精度海拔高度换算（基于国际标准大气压高模型）。
  - Bosch BSEC 算法空气质量指数（IAQ 0~500）与等效二氧化碳浓度（eCO2 ppm），辅助判断雪茄醇化挥发与通风换气时机。
- **动态双曲线趋势图（支持缩放与平移）**：
  - 双层时间序列：**RAM 高频实时缓冲（每 10s 采样）** + **NVS 24 小时整点长周期持久化**。
  - 开机 10 秒即可连线成像，杜绝新开机空白；支持 10m、1h、6h、24h 多级无级缩放与历史数据回溯平移。
- **极简低功耗电源管理**：
  - 符合 M5Stack 统一操作逻辑的电源键交互（单击重启、双击彻底断电）。
  - 开机自动单次 Wi-Fi NTP 校时至 BM8563 硬件 RTC，授时完毕立即彻底关闭 Wi-Fi 射频，纯离线极低功耗长效运行。
  - 屏幕智能分级刷新：每分钟仅局部刷新顶部状态栏，整点与按键交互快速全屏更新。

## 🕹️ 交互按键操作指南

### 1. 模式与界面键（G5 / EXT 按键）
- **短按单击**：
  - 选单未打开时：在【主仪表盘】与【空气质量实验室 (Air Quality Lab)】之间无缝循环切换；
  - 选单打开时：**取消并退出选单**，保持原功耗模式不变。
- **长按 (>= 800ms)**：**呼出【采样功耗模式选单 (SELECT POWER MODE)】**。

### 2. 选单导航与确认（选单开启时）
- **G37（拨轮 UP）**：向上移动光标。
- **G39（拨轮 DOWN）**：向下移动光标。
- **G38（拨轮按下 MID）**：**确认选择并立即生效**（配置自动持久化至 NVS，掉电重启不丢失）。

### 3. 电源键（G27，机身正面丝印 POWER）
- **单击**：ESP32 软重启（重启前自动将当前历史记录安全刷入 NVS）。
- **双击**：**彻底关机断电**（关闭内部电源保持引脚 GPIO 12，绿色电源指示灯熄灭，墨水屏保留关机前的画面不耗电）。

### 4. 顶部三向拨轮滚轮（G37 / G38 / G39）（常规状态下）

| 按键 | 模式：**缩放 (ZOOM)**（默认） | 模式：**平移 (PAN)** | 备注 |
| :--- | :--- | :--- | :--- |
| **G38（拨轮中心下按）** | **短按单击**：切换至【平移 (PAN)】模式 | **短按单击**：切换回【缩放 (ZOOM)】模式 | 在【Mode 4 按需采样】下长按 1 秒触发单次即时采样；其他模式长按 2 秒关机 |
| **G37（拨轮向上推 UP）** | **放大时间轴**（微观细节）：<br>`7d` $\to$ `5d` $\to$ `2d` $\to$ `24h` $\to$ `6h` $\to$ `1h` $\to$ `10m` $\to$ `5m` | **向过去平移**（向左回溯查看早前记录，最长支持 7 天回溯） | 步长随当前视窗自动适配 (30s~1d) |
| **G39（拨轮向下推 DOWN）** | **缩小时间轴**（宏观走势）：<br>`5m` $\to$ `10m` $\to$ `1h` $\to$ `6h` $\to$ `24h` $\to$ `2d` $\to$ `5d` $\to$ `7d` | **向最新时刻平移**（向右平移直达当前 `Now`） | 偏移量到当前时间自动归零锁定 |

## 🔋 四档采样功耗方案详解

系统支持针对不同场景的四档采样模式，兼顾实时性与超长待机：

| 模式名称 | 运行机制与休眠策略 | 预期待机时长 (390mAh) | 最佳应用场景 |
| :--- | :--- | :--- | :--- |
| **1. Realtime (实时采样)** | • 240MHz CPU 全速活跃<br>• BSEC 3 秒高速连续采样 | **约 9 ~ 12 小时** | 连电脑 USB 供电调试、刚换环境快速捕捉气味演变 |
| **2. Balanced (均衡模式，推荐)** | • 80MHz CPU + 动态 **Light-Sleep** 浅睡<br>• 所有按键低电平中断唤醒（响应时间 < 1ms） | **约 5 ~ 7 天** | 日常桌面/随身携带，既省电又拥有丝滑无延迟的滚轮交互 |
| **3. Eco ULP (长效续航)** | • 10分钟/600秒 周期采样<br>• 刷屏后进入 **Deep-Sleep**，定时/按键唤醒<br>• **BSEC 状态自动保存在 RTC 内存**，零基线漂移 | **约 45 ~ 60 天（1.5 ~ 2 个月）** | 长期闭盒静置于密闭雪茄箱、地下酒窖或衣橱中，自动定期巡检记账 |
| **4. On-Demand (按需采样)** | • 平时 **100% 深度休眠**，屏幕静态零功耗保持<br>• 按键唤醒或长按 G38 触发单次即时加热测量，测完即睡 | **数月以上（2 ~ 4 个月+）** | 极少开盒的长期藏品养护，仅在人工开箱巡检时随手按键测试 |

## 📊 关键传感器读数解读

### 1. 主页面左下角：气压与海拔高度
- **第一行 `P:%.1fhPa`**：当前环境实时大气压强（例如标准海平面气压约为 1013.25 hPa）。
- **第二行 `%.0f m`**：根据国际民航与气象标准压高公式自动换算的海拔高度：
  $$h = 44330.0 \times \left(1.0 - \left(\frac{P}{1013.25}\right)^{0.1903}\right)\text{ (米)}$$

### 2. 空气质量与博世 BSEC 算法多维解析（页面 1 & 页面 2）
由博世 BME688 传感器内部加热器周期性加热金属氧化物敏感层，经博世 BSEC 神经网络算法解算：
- **Static IAQ (静态空气质量指数)**：
  - 基于固定环境基线计算，**专门针对恒定放置的固定场所（如雪茄保湿箱、衣橱、地下酒窖、卧室）**。消除人为短暂走动或微弱气流引起的算法漂移，更能代表雪茄长期陈化环境的真正变化。
- **Realtime IAQ (实时动态 IAQ)**：
  - 考虑了人体对室内瞬时气味突变的敏感程度，常用于随身携带或移动探测。
  - **0 ~ 50**：优 (Excellent/OK)；**51 ~ 100**：良 (Good/MED)；**101 ~ 150+**：稍差/污染 (WARN，需开窗通风)。
- **bVOC (ppm，呼出等效挥发性有机化合物)**：
  - 精确测量醇类、醛类、酮类、烟草陈化挥发物等 VOC 浓度（典型纯净空气 < 0.3 ppm）。
- **eCO2 (ppm，等效二氧化碳)**：
  - 由 VOC 和氢气相关性换算得出（自然空气约 400~600 ppm；密闭憋闷时超过 1000 ppm）。
- **Gas Resistance (kΩ，气敏电阻)**：
  - MOX 传感器硬件原生测得的电阻绝对值。空气越纯净阻值越高（几十至数百 kΩ）；遭遇还原性气体或异味时阻值骤降。适合极客观察传感器底层硬件响应。
- **BSEC Accuracy (0 ~ 3 校准等级)**：
  - `Lv 0`：传感器未稳定或刚上电；
  - `Lv 1`：初步基线适应中；
  - `Lv 2`：部分校准；
  - `Lv 3`：完全校准（Full Calibration），数据具有最高准确度与参考价值。
- **Sensor Status (状态标签)**：
  - `STAB`：加热器达到稳定工作温度；
  - `RUN-IN`：传感器已完成初次加热器老化磨合期。

## 🔍 墨水屏硬件批次与驱动兼容性说明

M5Stack CoreInk 在不同生产周期中搭载了不同型号的 1.54 英寸 200×200 E-Ink 电子墨水屏面板：

| 面板型号 | 控制器芯片 | 硬件读出 ID | 特性与批次说明 |
| :--- | :--- | :--- | :--- |
| **GDEW0154D67** | **SSD1681** | `0x00010001` | 经典/常见批次，双帧显存差分驱动架构 |
| **GDEW0154M09** | **UC8151** | `0x00F00000u` / `0x00F01600u` | 新生产批次（如 2023 年批次），具有不同的寄存器配置与波形表 |

> [!WARNING]
> **踩坑与设计注意**：
> 两种面板的 SPI 通信指令集、波形控制表（LUT）及显存映射截然不同。若在代码中硬编码某一型号（如强制绑定 `Panel_GDEW0154M09`），在 D67 面板设备上运行时，所有局部刷新和画图指令都会被控制器无视，导致**串口日志持续打印传感器数据，但物理屏幕完全冻结在开机画面**。

### 本项目的平滑无闪自适应驱动方案

为了在 **Eco ULP (10分钟周期深睡)** 模式下实现**零黑白全屏闪烁、开机不冻结、自适应任意批次**的完美体验，本项目在唤醒流程中采用了如下机制：

1. **绕过官方强制清屏**：
   - 官方 `M5Core-Ink` 库的 `M5.begin()` 内部会执行 `Ink_eSPI::begin()`，其中写死了全屏反色清屏指令 `clear(TFT_BLACK)`，会导致每次休眠唤醒都出现剧烈黑白闪烁。
   - 本项目在休眠唤醒分支使用 `M5.begin(false, true, false)` 屏蔽默认屏幕启动，保留硬件供电与 I2C。
2. **底层自适应探针初始化 (`init_without_reset`)**：
   - 调用 M5GFX 提供的 `M5.M5Ink.init_without_reset(false)`，由驱动层实时读取面板的硬件 ID，动态加载对应的 D67 或 M09 驱动实例。
   - 传入 `use_clear = false`，不向墨水屏发送任何硬件复位或多阶段清屏波形，完整保留上一帧画面。
3. **差分局刷与高压电荷泵管理**：
   - 唤醒后调用 `powerHVON()` 重新开启墨水屏高压发生器；
   - 采用 `epd_mode_t::epd_fast` 局刷模式将最新传感器数据与时间推送到屏幕；
   - 待渲染彻底完成后（`waitDisplay()`），休眠前仅调用 `powerHVOFF()` 切断高压输出，**绝不发送清除显存的 `0x07, 0xA5` DeepSleep 指令**，使控制器显存始终与物理画面保持同步，实现下一次唤醒的无缝差分刷新。

## 🚀 编译与固件烧录

本项目基于 **PlatformIO** 构建，无需繁琐的手动配置依赖库。

### 1. 配置 Wi-Fi（用于开机首次 NTP 对时，可选）
复制 `src/config.example.h` 为 `src/config.h`（已加入 `.gitignore` 防止密码意外上传），填入您的 Wi-Fi 热点信息：
```cpp
const WifiCredential WIFI_AP_LIST[] = {
    {"Your_WiFi_SSID_1", "Your_WiFi_Password_1"},
    {"Your_WiFi_SSID_2", "Your_WiFi_Password_2"}
};
```
*(系统支持多 AP 自动扫描优先连接最强热点；若不配置 Wi-Fi，系统将自动跳过并直接依靠板载 BM8563 硬件 RTC 走时)*


### 2. 编译并烧录固件
连接 M5Stack CoreInk 至电脑 USB 端口，在终端中执行：
```bash
# 编译固件
pio run

# 烧录固件
pio run --target upload

# 查看串口监视器
pio device monitor
```
